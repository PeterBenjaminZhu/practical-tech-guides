# dS4 几何

de Sitter (dS) 时空具有正曲率；四维情形记为 dS4，曲率长度为 $\ell>0$。[ds4.nb](../examples/ds4/ds4.nb) 使用 static patch 的球坐标，其 metric 为

$$
ds^2=-\left(1-\frac{r^2}{\ell^2}\right)dt^2+\frac{dr^2}{1-r^2/\ell^2}+r^2(d\theta^2+\sin^2\theta\,d\phi^2),\qquad 0<r<\ell.
$$

预期几何关系为 $R_{ab}=3g_{ab}/\ell^2$、$R=12/\ell^2$，对应 $\Lambda=3/\ell^2$ 的真空 Einstein 方程。$r=\ell$ 是 static patch 的 cosmological horizon，球坐标在 $r=0$ 和两极退化。这个 chart 覆盖 de Sitter 的一部分；全局性质需要额外的坐标分析。

Notebook 依次定义 chart、正曲率长度及 metric，再计算所需几何量：

```wolfram
Needs["xAct`xCoba`"];
DefManifold[M, 4, {a, b, c, d, e, f}];
DefChart[ch, M, {1, 2, 3, 4}, {t[], r[], theta[], phi[]}];
DefConstantSymbol[radius];
DefMetric[-1, g[-a, -b], CD, {";", "D"}];
$Assumptions = radius > 0 && 0 < r[] < radius && 0 < theta[] < Pi &&
  Element[{t[], phi[]}, Reals];
metricMatrix = DiagonalMatrix[{
  -(1 - r[]^2/radius^2), 1/(1 - r[]^2/radius^2),
  r[]^2, r[]^2 Sin[theta[]]^2}];
MetricInBasis[g, -ch, metricMatrix];
MetricCompute[g, ch, {"Riemann"[-1, -1, -1, -1],
  "Ricci"[-1, -1], "RicciScalar"[], "Einstein"[-1, -1],
  "Kretschmann"[]}, CVSimplify -> Simplify];
ricci = ToValues[ComponentArray[ToBasis[ch][RicciCD[-a, -b]]]];
scalar = ToValues[RicciScalarCD[]];
kretschmann = ToValues[KretschmannCD[]];
curvature = ToValues[ComponentArray[ToBasis[ch][RiemannCD[-a, -b, -c, -d]]]];
einstein = ToValues[ComponentArray[ToBasis[ch][EinsteinCD[-a, -b]]]];
{ricci, scalar, kretschmann, einstein}
```

`radius` 对应 $\ell$。解析预期还包括 Kretschmann scalar $24/\ell^4$；Notebook 用所有四指标分量检查正 sectional curvature，用 `einstein+3metricMatrix/radius^2` 检查真空场方程。该 scalar 在 $r=\ell$ 的极限有限，这为判断 static chart 的边界提供局部曲率信息。若 `Simplify` 未确认矩阵相等，检查 $0<r<\ell$ 和角度范围是否已设定，以及输入是否使用 `r[]`、`theta[]`。这些表达式为解析预期；实际输出由案例记录确定。

[实际导出结果](../examples/ds4/outputs/results.json)记录 $R=12/\ell^2$ 和 Kretschmann scalar $24/\ell^4$，五项检查均为 `true`。独立核验和图形界面状态查看案例 verification 记录。

运行 Notebook，检查 chart、metric 和 domain，再比较曲率与 Einstein tensor。如果使用其他 chart，应通过坐标变换或曲率不变量比较共同区域。改变 $\ell$ 后重新计算，并维持 $0<r<\ell$ 的前提；实际输出和核验状态见案例的 `verification.md`。
